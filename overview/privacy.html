Overview Uploader · Privacy Policy

Last updated: 26 November 2026

Overview Uploader is a private tool used only by the owner of the YouTube channel Overview (@OverviewGeo) to upload and schedule the channel's own videos. It is not offered to anyone else.

YouTube API Services

Overview Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service. YouTube data is also subject to the Google Privacy Policy.

What data it accesses

With the owner's authorization (OAuth 2.0), the tool uploads the owner's video files, thumbnails and captions; sets title, description, tags, playlist and publication time; and reads the owner's channel ID to make sure it uploads to the right channel. It does not read, collect or store data about viewers or any other user.

How data is used, stored and shared

The OAuth token is stored only on the owner's computer. The only YouTube data kept is the list of IDs of the owner's own uploaded videos, in a local file. No data is sent to any other server, sold, shared with third parties or used for advertising. The tool does not use cookies or tracking.

Deletion and revoking access

Access can be revoked at any time at myaccount.google.com/permissions (Google security settings). On revocation, or on request, the local token and stored video IDs are deleted within 7 days. Stored data is never kept longer than 30 days without being refreshed by a new authorization.
